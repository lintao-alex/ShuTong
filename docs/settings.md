# 设置与覆盖

默认全部开启，解释阈值为 1；升级保留已有自定义阈值。

| 开关 | 作用 |
| --- | --- |
| enabled | 总开关；关闭时新回合不注入 ShuTong 策略，不自动记录 |
| profileEnabled | 关闭自动画像读取和写入；主干呈现可独立使用 |
| autoRecord | 是否自动累计解释次数；关掉后仍可利用已有记录 |
| adaptiveResponse | 是否按记录调整回答；关掉后仍可记录 |
| suppressKnownConcepts | 是否省略已知基础解释 |
| progressiveDetails | 是否准备主干和折叠详情 |
| preferArtifacts | 是否主动按内容选择表格、图或真实产物；用户明确要求优先 |
| panelEnabled | 是否自动在回答附面板链接；主动请求打开面板仍可用 |

总开关、画像开关会限制自动行为；用户明确要求检查和维护数据时仍可用管理工具。关闭功能不删除已有数据，不卸载 MCP 工具，也不承诺减少宿主加载工具的开销。

## 可选覆盖

优先级：默认值 → 全局 → 领域 → 当前任务 → 本轮回答。面板编辑全局值；领域和任务的覆盖可直接在对话里提出，例如“在这个任务里关闭主干与细节展开”。MCP `config` 使用 `scope=session` 和当前 `turnKey` 识别任务，无须用户知道内部编号。没有 turnKey 的恢复场景可通过配置查询取得已保存 selector。

领域 selector 是精确字符串匹配，依赖模型一致传入领域名称，不推断领域继承。`clearOverride` 删除指定层的配置，让低层重新生效；它不重置其他层。

“这次全文详细讲、不要折叠”“只给结论”“不画图”“只讨论不改代码”通过 `context.overrides` 影响本次输出，不修改长期记录。明确追问知识点时照常解释，不自动把它设为未掌握。

持久开关保存在本地 `settings.sqlite`；它与知识档案的 `knowledge.sqlite` 分开。面板“导出记录”导出知识点、阈值、别名和去重凭据，不包含开关、审计历史或暂存详情。完整迁移需同时备份两个数据库；备份运行中的 SQLite 应使用 SQLite backup API，而非只复制可能有事务进行的单个文件。
