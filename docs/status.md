# 开发进度

日期：2026-09-25

## 已完成

- 可扩展的用户信息与输出接口，支持多对多组合。
- SQLite 本地知识点记录、去重、手动标记、导入导出；默认解释阈值为 1，支持自定义。
- 输出策略、Codex Skill/MCP/生命周期钩子，以及本地知识点面板。
- 类型检查、31 项运行时测试、插件与 Skill 格式校验通过。
- 三轮真实 Codex CLI 对话验证：自动记录、读取已有记录、显式追问时重新解释。已在本机安装并启用个人插件。

## 影响范围

当前按本机系统用户的个人 Codex 配置启用，跨任务、跨项目共享本地档案；使用同一配置的 Codex CLI 也适用。用户已确认这一范围合理。尚无项目或会话级开关，不跨电脑同步。已有任务是否立即加载取决于宿主，试用请使用新任务。

## 验证结论与限制

现有测试证明功能流程可运行，尚未证明相比未启用工具时有额外收益。同一聊天里模型本来就可能避免重复解释，不能将该行为单独归功于 ShuTong。后续需要相同模型和问题的跨会话启用/关闭对照，同时检查关键信息保留和工具调用成本。

知识点识别由模型完成，仍可能漏记或采用不同粒度；当前面板是独立本地页面。其他宿主、所有重新生成路径、云同步和公共发布尚未完成。开源许可证待确定。

## 源码与构建

此仓库保存产品源码、依赖锁文件、测试和交付文档。插件运行时与含本机绝对路径的 `.mcp.json` 不提交，由 `pnpm build:plugin` 生成；新检出必须先安装依赖并构建，再验证或安装插件。

试用步骤见 [Codex 验证指南](try-in-codex.md)。开发过程记录保存在仓库外的工作区 `doc/` 中。
