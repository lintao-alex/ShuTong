# 开发进度

日期：2026-09-27

## 当前可用

- 可扩展的用户信息与输出接口，两侧多对多组合。
- 默认 1 次的本地机械计数、去重、手动标记、领域检索与显式别名；升级保留旧阈值和次数。
- 回答主干、命名详情节点及按需展开；隐藏详情不提前计数；父路径内容检索和简短结论回流。
- 总开关及独立记录/画像/输出/呈现开关，支持全局、领域、任务和回答覆盖。
- 本地回答/知识点/设置三视图，变更审计与撤销、导出/清空；命令行可直接修正名称和次数。
- Codex Skill/MCP/钩子、独立的无画像输出 Skill、JSON Schema 和三种安装路径说明。

## 验证

类型检查和 100 项测试通过，其中包括 16 个固定策略场景、真实 stdio MCP 与本地 HTTP 面板联动、数据库迁移、禁用行为、父路径隔离、清除摘要、旧面板升级替换、正文自动提取及旧协议兼容。插件和两份 Skill 格式校验通过。

在本机 Codex CLI 0.155.0-alpha.16.4 验证了真实回答生成主干及四个详情节点，Stop 确认发布；浏览器实际点击展开，知识点页显示对应次数。三条安装钩子被发现、启用且仍受信任。

同配置新任务启用/关闭的一个对照中，聊天正文为 514 对 2323 字符，输出 Token 为 3715 对 1880。该样例首层更短，但生成成本更高。未证明一般收益、真实阅读耗时改善或重复基础解释相对原生模型的降低比例。

## 边界及后续

本机系统用户默认跨任务、跨项目共享；不跨电脑同步。原生消息折叠未实现，当前详情在独立本地页面，支持基础 Markdown、表格和代码块。识别知识点和关键风险依赖模型；结构校验不能保证未列出的风险一定被发现。已有任务可能持有旧工具，更新后应使用新任务。

当前以发送前主干检查稳定阅读层，短稿会额外传输一次。阅读轻松程度由用户日后反馈；保留现有关键条件校验和完整版覆盖，不继续扩大语义检查。成本对比先复用历史数据，按需另开小规模测试。第二宿主待实现，待 Codex 体验验证完成后再展开。云同步、学习建议、缺口发现和团队画像属于后续模块。许可证已确定为 MIT；公开源码仓库为 [lintao-alex/ShuTong](https://github.com/lintao-alex/ShuTong)。

## 历史：成本优化第一轮

主干默认只生成一次，Stop 从实际交付正文提取并检查关键句；旧协议兼容。工具返回和重复规则已精简。最新单样例相对上一安装版：input_tokens 99813→73939，output_tokens 3427→2556；正文 525→613 字符。中间两次尝试也已保留记录，首层长度稳定性仍未通过目标，不能宣称普遍更短或更省。当前安装版本为 `0.1.0+codex.20260926050330`。

## 主干检查与实际对照（前一轮）

当前安装 `0.1.0+codex.20260926090137`。新客户端提交短主干供预算检查，必要条件可扩展预算；最多修订一次，再失败直接回答。获批后核对真实交付是否一致，未匹配不发布详情。明确请求全文详解优先；请求“实施细节”本身不等于取消折叠。

两个问题各两次的四组样本中，预算与交付检查 4/4 通过；首层正文平均 593→373.5 字符（约 -37%），但 input/output tokens 平均约 +19%/+33%。另做显式详解测试，未折叠且未更改长期设置。中间四个误判全文详解的失败样本也保留。程序测试 69/69、Skill/插件校验和本机钩子检查通过。

这证明该组样本的长度与交付行为，不证明普遍收益或所有风险识别完整。有样例将缓存、文档恶意指令等具体安全措施放在详情里，语义覆盖仍需继续验收。开发报告及全部样本位于工作区 `doc/evaluation/2026-09-26-main-stability.md`。

## 前一轮：跨任务候选匹配与验证

安装版本 `0.1.0+codex.20260926101412`。修复模型在不同任务改变 ID／领域名导致旧记录漏命中的问题：返回有数量上限的字面候选，模型确认同一概念后直接使用规范 ID，不自动合并、写别名或判断掌握程度。配置开关、阈值及显式追问继续有效，数据格式不变。

真实种子两条记录均自动累计为 1。两次新任务的四个目标概念，修复前直接命中一项，修复后均返回候选并选用原 ID。三组隔离对照及明确追问完成，共 18 次模型运行（含种子和失败样本）；测量档案全部冻结且未改变。74 项代码回归与安装检查通过。

本批应用型问题中，无记录和关闭应用的对照也没有单独重讲目标通用定义，因此尚未证明额外减少重复解释或 Token 收益。后续关注真实冗余样例与关键条件覆盖，不把通路正常当作收益证据。

## 前一轮：详情关键条件覆盖

最终安装 `0.1.0+codex.20260927022119`。详情可声明 `requiredInTrunk`，与全局关键句一起检查是否出现在主干。漏项与超长共用一次修订机会，仍失败就直接回答，不发布详情。普通步骤无需增加警告；旧格式与已有记录兼容，用户无需新增日常操作。

80 项回归通过，包含权限旁路、文档指令、回退新写入、预算、普通步骤与旧格式；真实 MCP 验证字段传输和漏项修订。本机 CLI 0.158.0-alpha.2.1 两个固定问题均首次通过，主干 275/287 可读字符，实际交付经 Stop 确认。最终三钩子仍 trusted。

本次知识库首层带上了引用/缓存/日志边界和文档指令风险；迁移题仍把恢复验证只放在详情。未声明条件仍无法自动保证，语义覆盖部分完成。这不是新的收益对照，不据此声称普遍减少遗漏或节省 Token。完整记录在工作区 `doc/evaluation/2026-09-27-condition-coverage.md`。


## 前一轮：详情面板富文本

主干与详情支持标题、强调、列表、引用、表格、代码块及 http/https 链接；表格和代码可横向滚动。HTML 显示为文字，图片显示说明，不自动加载资源。Markdown 本地解析，原始记录及 MCP 数据格式不变，旧记录无需迁移。图示源码保留为代码，不执行或自动绘图。

84 项回归通过；真实浏览器验证表格、代码、嵌套展开，隐藏知识点未提前计数，展开后 1 次、重复展开仍为 1 次。未更改生成策略，不重复运行模型成本对照。
