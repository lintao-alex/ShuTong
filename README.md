# ShuTong

ShuTong 通过可扩展的用户信息与输出能力，减少 AI 协作中的重复解释和阅读负担。

## 产品结构

- **用户信息模块**：记录和管理用户信息，首项能力为知识点解释次数与用户手动标记。
- **输出模块**：使用相关用户信息调整输出，首项能力为减少重复的基础解释。

两侧支持多对多组合，为后续信息类型和输出能力保留扩展空间。

## 第一条实现路径

自动累计知识点解释次数，达到可配置阈值后默认省略基础解释，默认阈值为 1 次。用户也可以主动展开本次知识点列表并标记已掌握，获得同样的效果。用户再次提问时正常解释，关键风险与任务条件始终保留。

## 当前状态

已实现本地可验证版本：SQLite 用户信息存储、去重计数、自适应解释策略、Codex Skill/MCP/生命周期钩子，以及可打开的知识点面板。

已通过三轮真实 Codex 模型验证，支持一次解释后默认减少重复基础解释，明确追问时正常解释。知识点识别仍由模型完成，当前面板为本地独立页面；跨宿主兼容与开源许可证尚未确定。

## 本地验证

需要 Node.js 22.22.2 或以上兼容版本、pnpm 10.33.2。

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm check
pnpm demo
pnpm demo:profile
pnpm build:plugin
```

`demo` 验证组合接口；`demo:profile` 在临时数据库中验证默认阈值 1、重复计数保护及重新打开后的恢复，并自动清理演示数据。演示不调用模型、不记录真实用户信息。

模块职责和可选宿主探测见 [开发说明](docs/development.md)，查看与修改本地记录见 [本地用户信息使用说明](docs/local-profile.md)。
